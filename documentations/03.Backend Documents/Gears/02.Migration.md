## Foreign key viselkedés

```php
$table->foreignId('user_id')->constrained('users')->cascadeOnDelete();
```

Ha egy user törlődik, a hozzá tartozó `gears` rekordok is törlődnek
(`cascadeOnDelete`). Alternatíva lenne `restrictOnDelete()` (tiltani a
user törlését, amíg aktív hirdetése van) — jelenleg `cascadeOnDelete`
van érvényben.
