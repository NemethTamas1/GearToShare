> **Kapcsolódó dokumentumok:** [02. Migration](./02.Migration.md) · [03. Business Logic](./03.BuisnessLogic.md)

## Áttekintés

A `Gear` modell a platformon meghirdetett, bérelhető eszközöket
reprezentálja. Minden `Gear` rekordnak pontosan egy tulajdonosa van
(`user_id`), és 0..N képe (`gear_images`), 0..N bérlési rekordja
(`rentals`) tartozhat hozzá.

## Fillable mezők


## Kapcsolatok

```php
public function user(): BelongsTo
{
    return $this->belongsTo(User::class, 'user_id');
}

public function images(): HasMany
{
    return $this->hasMany(GearImage::class, 'gear_id');
}

public function rentals(): HasMany
{
    return $this->hasMany(Rental::class, 'gear_id');
}
```

| Kapcsolat | Típus | Irány |
|---|---|---|
| `user()` | `BelongsTo` | Gear → tulajdonos |
| `images()` | `HasMany` | Gear → hozzá tartozó képek |
| `rentals()` | `HasMany` | Gear → az összes bérlési rekordja (történeti, nem csak az aktív) |
