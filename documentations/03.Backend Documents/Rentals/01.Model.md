# Rentals Model

> **Fájl:** `app/Models/Rental.php`
> **Tábla:** `rentals`
> **Kapcsolódó dokumentumok:** [02. Migration](./02.Migration.md) · [03. Business Logic](./03.BusinessLogic.md)

## Áttekintés

A `Rental` modell köti össze a `gears` és `users` táblákat: egy
bérlési tranzakciót reprezentál egy adott eszközre, egy adott
bérlővel, egy adott időszakra. A tulajdonos nem közvetlen mező a
`rentals` táblán — a `gear.user_id`-n keresztül érhető el, elkerülve
a denormalizációt.

## Fillable mezők

```php
#[Fillable(['gear_id', 'renter_id', 'start_date', 'end_date', 'total_price'])]
```

| Mező | Miért NEM fillable |
|---|---|
| `status` | Kizárólag szerver-oldali state transition állíthatja — a kliens sosem küldhet közvetlen státuszváltást. Lásd: [Business Logic - Állapot](./03.BusinessLogic.md#állapotgép). |
| `handover_token` | Szerver generálja `accepted` állapotba lépéskor, QR-alapú átvétel-megerősítéshez. Lásd: [Business Logic — QR handover](./03.BusinessLogic.md#qr-alapú-átvétel-handover). |
| `handover_confirmed_at` | Csak a sikeres QR-szkennelés eredményeként íródik, sosem kliens input. |
| `barion_payment_id` | A Barion válaszából származik a fizetés indításakor, sosem a kliens küldi. |

## Kapcsolatok

```php
public function gear(): BelongsTo
{
    return $this->belongsTo(Gear::class, 'gear_id');
}

public function renter(): BelongsTo
{
    return $this->belongsTo(User::class, 'renter_id');
}
```

| Kapcsolat | Típus | Irány |
|---|---|---|
| `gear()` | `BelongsTo` | Rental → az érintett eszköz |
| `renter()` | `BelongsTo` | Rental → a bérlő |

**Nincs közvetlen `owner()` reláció** — a tulajdonos a `gear.user`-en
keresztül érhető el (`$rental->gear->user`), mert a tulajdonjog
mindig az eszközhöz kötött, nem a bérléshez.
