## Migráció

```php
Schema::create('rentals', function (Blueprint $table) {
    $table->id();
    $table->foreignId('gear_id')->constrained('gears')->cascadeOnDelete();
    $table->foreignId('renter_id')->constrained('users')->cascadeOnDelete();
    $table->date('start_date');
    $table->date('end_date');
    $table->decimal('total_price', 8, 2);
    $table->string('status', 20)->default('pending');
    $table->string('handover_token', 64)->nullable();
    $table->timestamp('handover_confirmed_at')->nullable();
    $table->string('barion_payment_id', 100)->nullable();
    $table->timestamps();
});
```

## Foreign key viselkedés

```php
$table->foreignId('gear_id')->constrained('gears')->cascadeOnDelete();
$table->foreignId('renter_id')->constrained('users')->cascadeOnDelete();
```

Ha egy `gear` vagy egy `user` (bérlőként) törlődik, a hozzá tartozó
`rentals` rekordok is törlődnek (`cascadeOnDelete`). Ez később
felülvizsgálandó lehet, ha a történeti bérlési adatok megőrzése
válik fontossá (pl. `restrictOnDelete()` vagy soft delete
bevezetése) — jelenleg `cascadeOnDelete` van érvényben, konzisztensen
a `gears` táblával.
