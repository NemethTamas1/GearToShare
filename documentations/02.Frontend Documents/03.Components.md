# Frontend Components

> **Kapcsolódó dokumentumok:** [01. Architecture](./01.Architecture.md)

## `Layout.tsx`

A védett oldalak közös váza. `NavBar` + `<Outlet />`. A `ProtectedRoute` (App.tsx-ben definiálva) rendereli ezt, miután ellenőrizte a bejelentkezést.

## `NavBar.tsx`

Fix fejléc: logó (bal) + `NavBarProfile` (jobb). Minden védett oldalon megjelenik, a `Layout`-on keresztül.

## `NavBarProfile.tsx`

Headless UI `Menu` komponensre épülő legördülő profil-menü. Tartalma:
- User neve + email (fejléc, nem kattintható)
- Bérléseim → `/rentals` (**útvonal még nincs definiálva az App.tsx-ben — jövőbeli feladat**)
- Profilom → `/profile`
- Kijelentkezés → `logout()` hívása, majd `navigate('/login')`

A monogram (`initials`) a bejelentkezett user nevéből számolt kezdőbetűk, nem statikus szöveg.
